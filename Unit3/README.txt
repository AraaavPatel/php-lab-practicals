PHP Programs 3.1 to 4.10

Database programs use:
Host: localhost
Username: root
Password: blank
Database: php_practical

Create the database first:
CREATE DATABASE php_practical;

Then run 4.2_create_table_mysqli.php or 4.2_create_table_pdo.php.

For 3.7 and 4.9, login credentials/data depend on the users table.
